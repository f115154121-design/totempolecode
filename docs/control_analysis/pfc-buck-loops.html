0　方法：四個步驟

  1. 平均模型（大訊號）：把開關在一個週期內取平均，電感電壓、電容電流寫成以 duty 為變數的方程式。令導數為零，就得到穩態解，也就是前饋。
  2. 線性化（小訊號）：在工作點附近加小擾動，只保留一階項。
  3. 迴路增益：受控體 × 控制器 × 延遲，畫 Bode 圖，讀出相位裕度（PM）與增益裕度（GM）。
  4. 驗證：用時域模擬（這頁是自己寫的平均模型模擬；你可以在 PSIM 用 AC Sweep）比對。

第 2 步唯一的技巧，是處理「兩個變數相乘」的項。以 Buck 的 \(d\cdot V_{bus}\) 為例，令 \(d=D+\hat d\)、\(V_{bus}=V+\hat v\)：

\[ d\,V_{bus} = DV + D\hat v + V\hat d + \underbrace{\hat d\,\hat v}_{\text{二階，丟掉}} \]

直流項 \(DV\) 回到第 1 步的穩態，剩下的 \(D\hat v + V\hat d\) 就是小訊號。看到 \(V\hat d\) 前面的 \(V\) 了嗎？這就是為什麼受控體增益會跟 \(V_{bus}\) 成正比，也是你兩個控制器都要「除以 \(V_{bus}\)」的原因。

1　PFC 電流環

1.1　平均模型與前饋

在整流後的座標裡，totem-pole 就是一個 boost。\(d\) 是儲能開關的 duty（程式裡寫 CMPA 時會取補數，這點註解已經寫清楚）：

\[ L\frac{di_L}{dt} = |v_{ac}| - (1-d)\,V_{bus} \]

令 \(di_L/dt=0\)，並讓 bus 等於目標 \(V_{ref}\)：

\[ d_{ff} = 1-\frac{|v_{ac}|}{V_{ref}} \]

1.2　加上比例控制：「虛擬電阻」

程式的控制律是 \(d = d_{ff} + \dfrac{K}{V_{bus}}(i_{ref}-i_L)\)。把它代回平均模型，\(V_{bus}\) 剛好約掉：

\[ L\frac{di_L}{dt} = |v_{ac}|\Big(1-\frac{V_{bus}}{V_{ref}}\Big) + K\,(i_{ref}-i_L) \]

這條式子很值得記住，它說了兩件事：

  • 當 \(V_{bus}=V_{ref}\) 時，第一項消失，電流只受 \(K(i_{ref}-i_L)\) 驅動。\(K\) 的單位是 Ω，它就像一顆串在電感上的「虛擬電阻」，時間常數 \(L/K\)，頻寬 \(f_c = K/(2\pi L)\)。
  • 當 bus 偏離 \(V_{ref}\) 時，第一項會產生電流誤差。這個項後面在 bus 耦合和電壓環兩節都會再出現。

1.3　小訊號與迴路增益

擾動 \(\hat d\) 對電流的影響是 \(\hat i_L/\hat d = V_{bus}/(sL)\)，乘上控制器 \(K/V_{bus}\)，再乘上數位延遲。延遲取 \(T_d \approx 1.5\,T_s\)：ADC 取樣後要等一拍才寫入 CMPA，PWM 的零階保持再貢獻半拍。在 20 kHz 下 \(T_d = 75\ \mu s\)：

\[ T_i(s)=\frac{K}{sL}\,e^{-sT_d} \qquad\Rightarrow\qquad f_c=\frac{K}{2\pi L},\qquad PM = 90^\circ - 360^\circ f_c T_d \]
電感值要確認。程式註解寫 \(L = 1.5658\) mH（量測值，\(K = 2\pi\cdot 945\cdot L\)），而我們先前討論用的是 632 µH。兩者結果差很多：1.566 mH 時 \(f_c\)=947 Hz、PM 64°；632 µH 時 \(f_c\)=2.3 kHz、PM 只有 27°。這頁預設用 1.566 mH，下面可以切換。
PFC 電感 L

PM 公式說明了延遲的代價：每 1 kHz 的頻寬會被 75 µs 的延遲吃掉 27°。在 \(f = 1/(4T_d) = 3.33\) kHz 時延遲剛好貢獻 −90°，加上積分器的 −90°，就是 −180°。單看電流環，K 的上限是讓 \(f_c\) 碰到這個頻率，也就是 \(K_{max}=2\pi L\cdot 3333 \approx 33\)。但下一節會看到，真正的上限低得多。

2　Bus 與 Buck 的耦合（這次最重要的發現）

2.1　Buck 前饋讓它變成「直流變壓器」

Busloop() 用的是 \(d_b = V_o^*/V_{ref}\)。對 Buck 來說，\(V_o = d_b V_{bus}\)，所以在低頻（遠低於 Buck 的 LC 諧振 392 Hz）時：

\[ V_{bus} \approx \frac{V_o}{d_b} = V_{ref}\cdot\frac{V_o}{V_o^*} \]

只要 \(V_o = V_o^*\)，bus 就自動跟著 \(V_{ref}\) 走。這就是你的 tracking bus 能成立的原因：兩個前饋用同一個 \(V_{ref}\)，彼此是一致的。

2.2　從 bus 看進 boost：延遲造成負電阻

現在問：如果 bus 電壓有一個擾動 \(\hat v_{bus}\)，boost 會從 bus 吸收多少電流？線性化 1.1 的平均模型（前饋用 \(V_{ref}\)，不受 \(\hat v_{bus}\) 影響）：

\[ sL\,\hat i_L = -(1-D)\,\hat v_{bus} - K e^{-sT_d}\,\hat i_L \quad\Rightarrow\quad \hat i_L = \frac{-(1-D)}{sL + K e^{-sT_d}}\,\hat v_{bus} \]

流進 bus 的電流是 \((1-D)\hat i_L\)，所以 boost 從 bus 看進去的等效導納是：

\[ Y_{boost}(j\omega) = \frac{(1-D)^2}{j\omega L + K e^{-j\omega T_d}},\qquad \operatorname{Re}\{Y_{boost}\} = \frac{(1-D)^2\,K\cos(\omega T_d)}{|j\omega L + K e^{-j\omega T_d}|^2} \]

實部就是等效電導。正的電導會吸收能量（提供阻尼），負的則會注入能量。關鍵在 \(\cos(\omega T_d)\)：

\[ \omega T_d > \frac{\pi}{2} \;\Longleftrightarrow\; f > \frac{1}{4T_d} = 3.33\ \text{kHz} \quad\Rightarrow\quad \text{boost 變成負電阻，而且 } K \text{ 越大越負} \]

2.3　Bus 的諧振剛好落在那裡

10 µF 的 bus 電容，和 Buck 電感 75 µH 折算到 bus 側（除以 \(d_b^2\)）形成諧振。2200 µF 對這個頻率來說等於短路：

\[ f_{bus} = \frac{1}{2\pi\sqrt{(L_b/d_b^2)\,C_{bus}}} = \frac{d_b}{2\pi\sqrt{L_b C_{bus}}} \]

設計上的選項（未修改程式，供你評估）
  • 把 K 降到 6–7：模擬 THD 分別為 6.6%、5.8%，換來足夠的穩定裕度。
  • 縮短延遲：例如提早 ADC 觸發、或用 ePWM 的立即載入，讓 \(1/(4T_d)\) 往高頻移。

3　Duty 斜率限制

前饋在零交越附近變化最快。對 \(d_{ff}=1-|v_{ac}|/V_{ref}\) 微分（零交越附近 \(V_{ref}=140\) V）：

\[ \left|\frac{d\,d_{ff}}{dt}\right|_{max} = \frac{\omega V_m}{V_{ref}} = \frac{377\times 163}{140} = 439\ \text{s}^{-1} \;\Rightarrow\; 439\times 50\,\mu s = 0.022\ \text{每拍} \]

DUTY_SLEW_MAX = 0.01 只有需求的一半。duty 跟不上時，\((1-d)V_{bus}\) 會小於 \(|v_{ac}|\)，電感電流就會一路衝上去。這個限制原本是為了啟動保護（註解寫得很清楚），但它在正常運轉時也一直在作用。

4　PFC 電壓環

4.1　為什麼要對 line cycle 取平均

電壓環每個 line cycle 只更新一次 \(I_{pre}\)，它看不到一個週期內的變化，所以受控體要寫成「一個 line cycle 的平均功率」。能量存在 2200 µF 上（10 µF 的 bus 只存 0.14 J，在 500 W 下只撐 0.29 ms）：

\[ C_oV_o\frac{dV_o}{dt} = \overline{p_{in}} - P_{load} \]

4.2　輸入功率：比預期多一項

電流由兩部分組成：參考值 \(I_{pre}|\sin\omega t|\)，以及 1.2 節「虛擬電阻」式子裡由 bus 偏差產生的那一項。把 2.1 的 \(V_{bus}=V_{ref}V_o/V_o^*\) 代入：

\[ i_L = I_{pre}|\sin\omega t| + \frac{|v_{ac}|}{K}\cdot\frac{V_o^*-V_o}{V_o^*} \]

乘上 \(|v_{ac}|\) 再對一個週期取平均（\(\overline{\sin^2}=1/2\)）：

\[ \overline{p_{in}} = \frac{V_m I_{pre}}{2} + \frac{V_m^2}{2K}\cdot\frac{V_o^*-V_o}{V_o^*} \]

第二項是一個「下垂」：Vo 偏高時輸入功率自動減少。即使電壓環完全不動，系統本身也會穩在某個電壓，只是有穩態誤差。這一項是電流環的 K 帶來的，以前的推導（只有 \(V_mI_{pre}/2\)）會漏掉它。

4.3　線性化

\[ G_v(s)=\frac{\hat v_o}{\hat i_{pre}} = \frac{V_m/2}{C_oV_o\,s + G_d},\qquad G_d = \underbrace{\frac{V_m^2}{2KV_o^*}}_{\text{下垂}=14.3\ \text{W/V}} + \underbrace{\frac{\partial P_{load}}{\partial V_o}}_{\text{電阻負載 }2V_o/R} \]

電阻負載 20 Ω 時 \(G_d = 14.3+10 = 24.3\) W/V，極點在 \(G_d/(2\pi C_oV_o) = 17.6\) Hz。如果 WPT 搭配定電壓控制後比較像定功率負載，第二項為 0，極點降到 10.3 Hz。

4.4　量測低通與取樣

lowpass() 每拍執行 \(V_{f} \mathrel{+}= z(V_o - V_f)\)，\(z=0.001568\)，等效時間常數 \(\tau = T_s/z = 31.9\) ms，也就是 5 Hz 的一階低通。

取樣固定在每個週期的同一個相位（integral1 ≈ 4.71 rad）。120 Hz 漣波在取樣點的值為 \(\cos(2\omega t_0 + 2\omega k/60) = \cos(2\omega t_0)\)，每次都一樣，所以漣波被取樣成一個固定偏移，不會傳進 \(I_{pre}\) 造成三次諧波。這就是不需要額外 notch filter 的原因。

4.5　z 域迴路增益

受控體連同低通寫成 \(G(s)=\dfrac{k}{(s+a)(s+b)}\)，其中 \(k=\dfrac{V_m}{2C_oV_o\tau}\)、\(a=\dfrac{G_d}{C_oV_o}\)、\(b=\dfrac1\tau\)。用零階保持離散化（\(T=1/60\) s），部分分式展開後：

\[ G(z) = \frac{k}{ab} + (1-z^{-1})\left[\frac{k/(a(a-b))}{1-e^{-aT}z^{-1}} + \frac{k/(b(b-a))}{1-e^{-bT}z^{-1}}\right] \]

程式的速度型 PI：\(I_{pre}[n]=I_{pre}[n-1]+K_p(V_e[n]-V_e[n-1])+K_i T\,V_e[n]\)，等價於

\[ C(z) = K_p + \frac{K_i T}{1-z^{-1}} \]

5　Buck（如果要改成閉迴路）

目前 Buck 是開迴路前饋，這是對的分工：能量平衡交給 PFC 電壓環，Buck 只當直流變壓器。這一節是給你未來考慮讓 Buck 閉迴路時用的。

5.1　受控體（含寄生電阻）

\[ G_{vd}(s) = V_{bus}\,\frac{Z_p}{sL_b + r_L + Z_p},\qquad Z_p = R\;\Big\|\;\Big(r_C+\frac{1}{sC_o}\Big) \]

近似成二階形式時：

\[ f_0 = \frac{1}{2\pi\sqrt{L_bC_o}} = 392\ \text{Hz},\qquad \frac{1}{Q}\approx \frac{Z_0}{R} + \frac{r_L+r_C}{Z_0},\qquad Z_0=\sqrt{L_b/C_o}=0.185\ \Omega \]

因為 \(Z_0\) 很小，負載電阻幾乎不提供阻尼（\(Z_0/R=0.009\)），Q 值完全由寄生電阻決定：理想元件時 Q ≈ 108，加上 \(r_L+r_C=50\) mΩ 後 Q ≈ 3.6。另有一個 ESR 零點 \(f_z = 1/(2\pi r_C C_o) = 3.6\) kHz。

5.2　符號與裕度

控制器 \(C(s)=\pm(K_p+K_i/s)/V_{bus}\)。用下面的切換鍵比較「+」與「−」：「−」等於整條相位平移 180°，諧振頻帶的正回授會被翻成負回授（所以理想元件時看起來收斂），但直流變成正回授。
