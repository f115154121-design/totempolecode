# 這台機器的理論

Totem-pole 無橋 PFC + Buck，後接雙邊 LCC 無線充電。

這份文件回答「為什麼這樣設計」，`../control_analysis/README.md` 回答「增益該設多少」。
建立整體理解時先讀這份，調參數時讀那份。

本文數字一律用本機實際值：
`L = 1.566 mH`、`Cbus = 10 µF`、`Lb = 75 µH`、`Co = 2200 µF`、`Vo* = 100 V`、
`Vrms ≈ 106~110 V`、`f_sw = 20 kHz`、`Ts = 50 µs`。

---

## §0 為什麼要 PFC

### 不做會怎樣

二極體整流橋後面直接掛大電容：只有在 `|vac| > Vcap` 的那一小段時間電容才充得進電，
其餘時間二極體反偏、電流為零。結果輸入電流是一串**又高又窄的脈衝**。

```
PF  ≈ 0.5 ~ 0.6
THD > 100%
```

危害不是「效率差」—— 基波功率一樣送到了。問題在諧波電流：三次諧波在三相系統的
中性線上是同相疊加（不是抵銷），中性線可能比相線還燙；而且電流尖峰會打壓電網電壓
波形。IEC 61000-3-2 就是管這個。

### 目標：把轉換器做成一顆電阻

PFC 的全部任務可以濃縮成一句話：

```
i(t) = v(t) / R_e
```

讓電網「看到」一顆電阻 `R_e`。電流自動與電壓同相、自動是正弦（因為電壓是正弦）。

`R_e` 不是實體電阻，是控制器製造出來的。它的值由外環決定：

```
R_e = Vrms² / P
```

要吸 600 W、110 V 時 `R_e = 110²/600 = 20.2 Ω`。**外環在調的其實就是這個模擬電阻值。**

### PF 和 THD 的關係

```
PF = P / (Vrms · Irms) = (I1 / Irms) · cos(φ1)
      \____失真因數____/   \_位移因數_/

失真因數 = 1 / sqrt(1 + THD²)
```

兩個因素獨立：波形不正弦（THD）扣一次，相位不對齊（φ1）再扣一次。

**診斷時一定要拆開看。** 2026-10-16 的實測就是案例：輸入並聯的 5 µF 電容造成 6.5° 的
位移角，與電流環、與波形品質完全無關。只看 PF 會誤判成控制器的問題。

## §1 為什麼是 totem-pole

### 從傳統 boost PFC 說起

```
AC ─ 整流橋(4顆二極體) ─ L ─ boost(1 MOSFET + 1 二極體) ─ Vbus
```

**問題：電流在任何時刻都要穿過整流橋的兩顆二極體。** 每顆壓降約 1 V，8 A 時：

```
P_loss = 2 × 1 V × 8 A = 16 W
```

這 16 W 跟 duty、跟負載率無關，是「入場費」。在 600 W 的機器上就吃掉 2.7% 的效率，
整流橋還要散熱。

### 無橋化

MOSFET 的通道可以雙向導通，導通時沒有二極體壓降，只有 `I²·Rds_on`。
那就用 MOSFET 取代整流橋。Totem-pole 的做法是**兩個半橋**：

```
          ┌── Q1 ──┬── Q3 ──┐
    L     │        │        │
AC ───────┤       Vbus      │
          │        │        │
          └── Q2 ──┴── Q4 ──┘
             快臂      慢臂
```

| | 切換頻率 | 角色 |
|---|---|---|
| **快臂** Q1/Q2 | 20 kHz | boost 的開關對 |
| **慢臂** Q3/Q4 | 60 Hz（線頻） | 跟著電壓極性換相，提供回流路徑 |

### 四個狀態

**正半周**（`vac > 0`）：Q4 恆通、Q3 恆斷，慢臂把中性點接到負軌。

1. **Q2 導通**（下管）→ 電感兩端是 `vac`，`di/dt = vac/L > 0`，**儲能**
2. **Q1 導通**（上管）→ 電感兩端是 `vac − Vbus < 0`，**放能到 bus**

**負半周**（`vac < 0`）：Q3 恆通、Q4 恆斷，Q1/Q2 角色互換。

這就是程式裡為什麼：

- `EPwm1`（快臂）吃 `CMPA`，每拍更新
- `EPwm2`（慢臂）用 `AQCSFRC` 軟體強制，只在過零換一次
- 而且 `b1 > 0` 與 `b1 < 0` 兩個分支的 `CMPA` 要**寫反**（`final_duty` vs `1 − final_duty`），
  因為同一顆 MOSFET 在兩個半周扮演的角色不同

最後這點就是 2026-10 那個極性 bug 的來源：duty 給反，電流環從負回授變成正回授。

### 為什麼以前做不出來

快臂在 CCM 下，MOSFET 關斷後電流會先走**本體二極體**，下一次對管導通時這顆二極體
要被反向恢復。矽 MOSFET 的本體二極體恢復特性很差（`Qrr` 大、`trr` 長），
恢復電流形同短路穿透，損耗極大、EMI 極糟。**所以 totem-pole 曾經是紙上拓樸。**

GaN HEMT 沒有本體二極體（反向導通靠通道），`Qrr ≈ 0`，totem-pole 才實用化。

**那本機用矽為什麼可以？**

1. `f_sw = 20 kHz` 很低。反向恢復損耗正比於頻率，20 kHz 是 100 kHz 的 1/5
2. 電流只有 8 A 級，`Qrr` 的絕對量不大

代價是 20 kHz 的電感漣波大（`ΔI ≈ 1 A p-p`，見 §7），磁件也大。這是個清楚的取捨，
不是疏忽。

## §2 boost 轉換律與「包絡式 Vbus」

### 基本式

一個切換週期內取平均（`d` = 儲能開關的導通比）：

```
L·di/dt = |vac| − (1−d)·Vbus
```

穩態（`di/dt = 0`）：

```
Vbus = |vac| / (1−d)
```

因為 `d ∈ [0,1)`，所以 **`Vbus ≥ |vac|` 永遠成立**。boost 只能升壓。

### 這條約束是硬的

如果 `Vbus < |vac|`，電流會**不受控地**經由本體二極體從輸入灌進 bus ——
控制器完全沒有辦法，因為 duty 怎麼調都阻止不了。

這就是啟動時反灌大電流的物理原因：`Vref` 設得比瞬時線電壓峰值低，
等於要求一個物理上不存在的工作點。

### 一般 PFC vs 本機

| | 一般 PFC | 本機 |
|---|---|---|
| Vbus | 固定 400 V | **`|vac| + 40`，下限 140 V** |
| duty 範圍 | 0.19 ~ 1.0（隨線電壓變化大） | **0.21 ~ 0.29（幾乎不變）** |
| bus 電容 | 幾百 µF 電解 | **10 µF** |

**包絡式 Vbus 的好處：**

```
d = 1 − |vac|/(|vac|+40) = 40/(|vac|+40)
```

`|vac|` 從 0 到 150 V，`d` 只從 1.0 掉到 0.21。在有電流的區段（`|vac|` 大）duty 都很小，
**開關導通時間短、導通損耗低**；而且 Vbus 只有 190 V 而不是 400 V，**電壓應力減半**，
可以用低耐壓、低 `Rds_on` 的元件。

**代價：** Vbus 以 120 Hz 移動 → bus 上不能放大電容 → 能量緩衝必須搬到別的地方。
這就是 §5。

### 前饋就是整形機制，不是修正項

程式裡這一行：

```c
feedforward = 1 - (Vac_in / Vref);
```

不是「幫控制器省點力」的補償，**它本身就是讓 Vbus 等於 Vref 的機制**：

```
d = 1 − |vac|/Vref   代回   Vbus = |vac|/(1−d) = |vac|/(|vac|/Vref) = Vref
```

Vbus 會自己長成 Vref 的形狀。電流環的 PI 只是在修這個開迴路解的殘差。

理解這點很重要：**`Vref` 不是某個迴路的設定點，它是直接寫進 duty 的整形函數。**

## §3 電流整形

### 為什麼是平均電流模式

| 方式 | 控制的量 | 問題 |
|---|---|---|
| 峰值電流模式 | 每拍的電流峰值 | 峰值 ≠ 平均，兩者差 `ΔI/2` 隨線電壓變化 → 失真 |
| 滯環 | 電流帶寬 | 開關頻率不固定 → EMI 難處理 |
| **平均電流模式** | 每拍的平均電流 | 要一個真正的電流環，但波形最乾淨 |

本機用平均電流模式：ADC 在 PWM 計數器的中點取樣，三角波漣波在中點剛好等於平均值
（上下計數 + 中點取樣，是硬體幫你做的平均）。

### 控制律與「虛擬電阻」

```
d = d_ff + Kp·(iref − i) ,   Kp = K/Vbus
```

代回電感方程式：

```
L·di/dt = |vac| − (1 − d_ff − Kp·e)·Vbus
        = |vac| − |vac|·Vbus/Vref + Kp·Vbus·e
        = |vac|·(1 − Vbus/Vref) + K·e          ← Vbus 被 Kp 的分母約掉了
```

第一項在 `Vbus = Vref` 時歸零。剩下：

```
L·di/dt = K·(iref − i)
```

**`K` 的單位是歐姆。** 它的作用像一顆串在電感上的虛擬電阻：

```
τ  = L/K      = 1.566m/7 = 224 µs
fc = K/(2πL)  = 711 Hz
```

這個觀點比 Bode 圖直覺：K 越大，電感「看起來」越像電阻，電流就越快跟上命令。

### 為什麼 Kp 要除以 Vbus

小訊號線性化時 `d·Vbus ≈ D·V̂bus + Vbus·d̂`。
**duty 擾動前面乘的是 Vbus**，所以受控體增益 `Vbus/(sL)` 與 Vbus 成正比。

本機的 Vbus 在一個線週期內從 140 V 擺到 190 V（1.36 倍）。Kp 若固定，迴路增益就跟著
擺 1.36 倍，交越頻率與相位裕度跟著變 —— 線電壓峰值附近剛好穩定，過零附近就過度補償。

`Kp = K/Vbus` 把它抵銷：

```
T(s) = Kp · Vbus/(sL) = K/(sL)      ← 與 Vbus 無關
fc   = K/(2πL)
```

**交越頻率在整個線週期內恆定。** 這是除以 Vbus 的唯一目的，不是經驗做法。

老師黑板上的 `Kp·Vo = 10`、`ωc = Vo·Kp/L` 講的就是這件事。

## §4 外環為什麼必須很慢

這是 PFC 最常被做錯的地方。

### 機制

電流參考的形狀是：

```
Iref(t) = Ipre · |cos(θ)|
```

`Ipre` 是外環給的**振幅命令**，它應該是直流。

但外環的輸入（Vo 或 Vbus）天生帶 120 Hz 漣波（§5 會證明這是物理必然）。
如果外環頻寬夠高，這個 120 Hz 就會穿過去：

```
Ipre(t) = I0 + I2·cos(2ωt)
```

乘進參考：

```
Iref = [I0 + I2·cos(2ωt)] · cos(ωt)
     = I0·cos(ωt) + I2·cos(2ωt)·cos(ωt)
```

用積化和差 `cos(2ωt)·cos(ωt) = ½[cos(ωt) + cos(3ωt)]`：

```
Iref = (I0 + I2/2)·cos(ωt) + (I2/2)·cos(3ωt)
                              \____三次諧波____/
```

**120 Hz 的振幅漣波會直接變成三次諧波。**

量化：

```
THD3 ≈ (I2/2)/I0 = α/2          α = Ipre 的 120 Hz 相對漣波
```

要讓這一項造成的 THD < 2%，需要 `α < 4%`。

### 本機的做法

```c
if(theta > 4.71 && theta < 4.73)   // θ ≈ 3π/2，每個線週期一次
{
    if(VfbLock == 0) { /* ...更新 Vpi... */ }
}
```

**每個線週期只更新一次，而且固定在同一個相位。** 這不只是「慢」，還是個漂亮的技巧：

以 60 Hz 取樣一個 120 Hz 訊號，120 Hz 剛好是取樣率的 2 倍，**混疊到直流**。
漣波因此變成一個固定偏移（大小取決於取樣相位），而不是會傳下去的波動。
固定偏移只讓 Vo 的穩態值差一點，不會產生諧波。

這是同步取樣（synchronous sampling），比低通濾波器乾淨得多 —— 低通要把 120 Hz 壓到
4% 以下需要極低的轉角頻率，會嚴重拖慢暫態響應。

### 設計規則

```
電壓環頻寬 ≪ 120 Hz            一般取 10~20 Hz
本機：ωz = Vki/Vkp = 1/0.03 = 33 rad/s ≈ 5.3 Hz，取樣率 60 Hz
```

**推論：PFC 的負載暫態響應天生就慢（百毫秒級）。** 這不是調不好，是物理限制。
要快速響應只能靠後級或輸出電容。

## §5 能量緩衝在哪（關鍵）

**這一節決定 Buck 該控什麼。**

### 單相輸入的瞬時功率必然脈動

```
p(t) = Vp·sin(ωt) × Ip·sin(ωt)
     = Vp·Ip·sin²(ωt)
     = (Vp·Ip/2)·(1 − cos 2ωt)
     = P·(1 − cos 2ωt)
```

**從 0 擺到 2P，以 120 Hz 脈動。**

這是 PF = 1 的**結果**，不是缺陷 —— 電流與電壓同相，兩者同時過零，
那一刻的瞬時功率必定是零。

但負載要的是定功率 P。差額 `P·cos(2ωt)` 必須有東西吃下來。

### 需要多少儲能

對差額積分：

```
E(t)      = ∫ P·cos(2ωt) dt = P·sin(2ωt)/(2ω)
ΔE(峰對峰) = P/ω = 600/377 = 1.59 J          （600 W）
```

### 這 1.59 J 不可能放在 Cbus

電容能量 `E = ½CV²`，微分得 `ΔE = C·V·ΔV`，所以 `ΔV = ΔE/(C·V)`：

| 電容 | 算式 | 需要的電壓擺幅 |
|---|---|---|
| `Cbus = 10 µF` @ 170 V | `1.59/(10µ × 170)` | **936 V** ← 物理上不可能 |
| `Co = 2200 µF` @ 100 V | `1.59/(2200µ × 100)` | **7.2 V** ← 合理 |

**本機的能量緩衝器是輸出電容 Co，不是 bus 電容。**

這跟教科書相反。一般 PFC 把大電解放在 bus（400 V / 幾百 µF），後級只是 DC-DC。
本機因為 Vbus 要能自由跟著 `|vac|+40` 移動，bus 上就**不能**有大電容釘住它，
大電容只好放到 Buck 之後。

### 推論一：Vo 本來就該有 120 Hz 漣波

600 W 時 `±3.6 V`（7.2% p-p）。

**這不是缺陷，是緩衝在工作的證據。** 看到它不要想去消除它。

### 推論二：Buck 必須控 Vbus，不能緊控 Vo

| 架構 | 會發生什麼 |
|---|---|
| **Buck 控 Vbus** | Vbus 被釘在 Vref，120 Hz 能量自然穿過 Buck 流進 Co，Vo 漣波，Co 緩衝。各司其職 |
| Buck 緊控 Vo | Buck 努力壓平 Vo → 1.59 J 被擋在 bus 側 → 10 µF 吃不下 → Vbus 爆衝，迴路跟物理打架 |

**老師三環圖的配置不是任選的，是這個拓樸唯一能成立的。**

之前糾結的「兩級不能同時積分 Vo」，底層原因就在這裡。

### 例外

如果 Buck 的頻寬**遠低於** 120 Hz，它「控 Vo」也不會打架 —— 因為它根本看不到 120 Hz。
但那樣它對 Vbus 就沒有調節能力，Vbus 完全靠 PFC 的前饋，等於現狀。

所以真正的選擇是：**要不要讓 Buck 有頻寬。** 要的話，它只能控 Vbus。

## §6 三環結構

```
             ┌─────────────── Vo 環（慢，~1 Hz）───────────────┐
             │                                                  │
Vo* ──(−)──→ Gcv ──→ Ipre ──×──→ iac,ref ──(−)──→ Gci ──→ d ──→ [PFC] ──→ Vbus ──→ [Buck] ──→ Vo
      │                      │              │                                        │
      Vo                  |cos θ|          iac                                       │
                                                                                     │
Vbus,ref ──(−)──→ Gcv2 ──→ d_buck ────────────────────────────────────────→ [Buck] ──┘
         │
        Vbus
```

| 環 | 控制的量 | 經由 | 頻寬 | 為什麼是這個頻寬 |
|---|---|---|---|---|
| Vo 環 | 能量平衡 | 設定 `Ipre` | **~1 Hz** | §4：≪120 Hz，否則產生三次諧波 |
| 電流環 | 輸入電流形狀 | PFC duty | **600~1k Hz** | 要追 60 Hz 基波與諧波；上限由延遲與 bus 諧振決定 |
| Vbus 環 | bus 電壓 | Buck duty | **~1k Hz** | §5：讓 120 Hz 能量通過；上限受電流環耦合 |

### 符號規則

誤差一律 `e = ref − fb`，控制器符號必須讓迴路增益 `L = C·P` 在直流為正。

| 迴路 | `∂(受控量)/∂d` | 符號 |
|---|---|---|
| PFC 電流環 | `> 0`（duty 大 = 電感充電久） | **＋** |
| Buck 控 Vo | `+Vbus` | **＋** |
| **Buck 控 Vbus** | **`< 0`**（Buck 是 bus 的負載，duty 大 = 抽更多能量） | **−** |

最後一項是反直覺的來源。水桶比喻：
**電流環的 duty 是進水，Vbus 環的 duty 是出水。** 同一個水位，兩個閥門方向相反。

等價寫法：把迴路寫在 `1−d` 上。從輸出端看，Buck 這一級是把 Vo 升到 Vbus 的 boost，
`∂Vbus/∂(1−d) > 0`，控制器回到 ＋，負號被變數換算吸收。

PSIM 實測：用 ＋ 時 `Vkp = 0.0026` 發散，用 − 時同值正常。
靜態翻號條件 `Vkp < Vo/Vbus²`。

### 為什麼老師要做頻寬交互研究

注意電流環（600~1k Hz）和 Vbus 環（~1k Hz）**幾乎重疊**。

兩個迴路共用同一個狀態（Vbus）：電流環往 bus 灌能量，Vbus 環從 bus 抽能量。
頻寬靠得這麼近時，兩者會互相看見對方的動態，不能再當成獨立設計。

這就是那個研究要回答的問題：**兩者要分開多少才算安全。**

## §7 離散實作

### 延遲從哪來

```
Td = 1.5·Ts = 75 µs
     │
     ├── 1.0 Ts：這一拍取樣、算完、寫進 CMPA，下一拍才生效
     └── 0.5 Ts：ZOH（duty 在整拍內保持不變，等效半拍延遲）
```

延遲吃相位，不吃增益：

```
相位損失 = 360° × fc × Td
```

`fc = 711 Hz` 時損失 19.2°。對純積分器受控體（`1/sL`，本身 −90°）配純 P：

```
PM = 90° − 360°·fc·Td = 90° − 19.2° = 70.8°
```

**交越頻率的硬上限**：`fc < 1/(4Td) = 3.33 kHz`（此時 PM = 0）。實務上留一半。

### 離散 PI（老師的推導）

```
Kp + Ki/s = Ki·(s/ωz + 1)/s            ωz = Ki/Kp（零點位置）

s → (z−1)/Ts

C(z) = [Kp(z−1) + Ki·Ts]/(z−1)

u[n] = u[n−1] + Kp·(e[n] − e[n−1]) + Ki·Ts·e[n]        ← 速度型
```

本機 `VoltageLoop()` 用的就是這個形式。

**但變增益時要用位置型。** `Kp = K/Vbus` 而 Vbus 在擺動，速度型會把舊 Kp 算出的
比例量凍在狀態裡。位置型（P 項 + 獨立積分狀態）每拍用當下的 Kp 重算：

```c
I_sum += Ki_Ts * e;
u = Kp*e + I_sum;
```

穩態兩者等價。細節與增益設計見 `../control_analysis/README.md` §8。

### 抗積分飽和

積分器後面只要有飽和（clamp、slew limit、duty cap），就必須處理 windup。
**反算法**最乾淨：

```c
u_raw  = Kp*e + I_sum;
u      = clamp(u_raw);
I_sum += (u - u_raw);     // 被削掉多少就從積分器退回多少
```

未飽和時修正量為零；飽和時積分器剛好被拉回「輸出等於限值」的狀態。

兩個本機特有的陷阱：

- 電流環的輸出後面還有 **slew limiter**，反算要對準 slew 之後的 `final_duty`
- 過零附近 `d_ff = 1 − 0/140 = 1.0`，duty 必定頂到上限，**那一段一定會飽和**

### 開關漣波與輸入濾波

```
ΔI = |vac| · d · Tsw / L
```

`|vac| = 150 V`、`d = 0.21`、`Tsw = 50 µs`、`L = 1.566 mH`：

```
ΔI = 1.0 A p-p            （峰值電流 8.2 A 的 12%）
```

這個漣波電流流出去會打在電源內阻抗上變成電壓擾動：

```
ΔV = Z_source(20 kHz) × ΔI
```

電源內阻抗在 20 kHz 幾乎全是電感性（`Z = ωLs`），即使 `Ls` 只有 160 µH 也有 20 Ω
→ 20 V p-p 的輸入電壓擾動。

**輸入差模電容就是在解這個：**

```
Zc(60 Hz)  = 1/(2π·60·C)       對基波幾乎開路
Zc(20 kHz) = 1/(2π·20k·C)      對漣波幾乎短路
```

1 µF 時兩者差 333 倍。代價是 60 Hz 的無效電流 `I_c = ωCV`，造成相位超前。
因為 `I_c` 固定不隨負載變，**輕載時角度最大**（實測數字見 `CLAUDE.md` 硬體一節）。
